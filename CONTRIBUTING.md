# Contribution

To contribute to the project:

 - Fork the repository
 - Commit your changes to your fork
 - Send PR

## PR

When creating a pull request:

 - Be concise
 - Specific
 - Straight to the point.

Changes made must have proper documentation
on why the change was made.
